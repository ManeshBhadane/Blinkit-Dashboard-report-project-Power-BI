# Blinkit-Dashboard-report-project-Power-BI
Interactive Power BI dashboard analysing Blinkit sales & operations data to identify high/low-performing product categories with KPI cards, slicers, and drill-throughs.
## Blinkit Sales & Operations Dashboard

**Tools:** Power BI | DAX | Power Query

### Overview
An interactive Power BI dashboard built to analyse Blinkit sales and 
operational data, identify high and low-performing product categories, 
and present key business insights to management for data-driven 
decision-making.

### Key Features
- KPI cards tracking sales performance and operational metrics
- Interactive slicers and drill-through visuals
- DAX measures for trend and pattern analysis
- High/low-performing product category identification
- Data cleaned and transformed using Power Query
- Repeatable and accurate reporting workflow

### Insights Delivered
- Identified top and bottom performing product categories by sales
- Surfaced operational trends to support inventory and supply decisions
- Enabled management to independently explore data via interactive visuals

### How to View
1. Download the ZIP file
2. Extract it
3. Open the `.pbix` file in Power BI Desktop
